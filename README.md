# Parallel Realms

A split-screen cooperative puzzle-platformer built in Unity, inspired by the concept of two parallel worlds where every action in one world affects the other.

## Overview

Parallel Realms follows two characters:

- 🏰 **Lena** – A medieval adventurer.
- 🤖 **Maya** – A futuristic explorer.

Both characters move simultaneously but exist in different worlds. Players must solve interconnected puzzles where actions performed by one character directly impact the other's environment.

---

## Features

- 🎮 Split-screen gameplay
- 🧩 Cooperative puzzle mechanics
- 🚪 Buttons and gate systems
- 🔘 Lever interactions
- 📍 Dynamic checkpoint system
- ☠️ Death & respawn system
- ⚡ Distance synchronization between characters
- 🎥 Third-person camera system
- ⚙️ Custom key rebinding system
- 🏃 Character movement with:
  - Walking
  - Sprinting
  - Sliding
  - Jumping
  - Run stop animations
